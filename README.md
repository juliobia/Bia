# Skylark: Deadline Run

An original offline 3D flight game for desktop Chrome. Entry for make.fun's "Make the best flight game".

**Play:** open `game/index.html` in Chrome (no server or internet needed).
**Build the entry:** `node main.ts` (Node 22.18+) writes `out/`.
